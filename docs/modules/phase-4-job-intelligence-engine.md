# Phase 4: Job Intelligence Engine (Completed)

## Overview
Phase 4 upgrades the keyword-based job matching system to a true Semantic Vector Search. Instead of just counting overlapping skill tags, the engine now uses an AI embedding model to understand the *meaning* behind a user's entire career profile (summary, skills, experience, projects) and matches it against the *meaning* of a job description. 

## Key Sub-modules & Architecture

### 1. Vector Database (pgvector)
- **Tooling**: We opted to use the `pgvector` extension natively within the existing Neon PostgreSQL database instead of introducing a separate service like ChromaDB.
- **Implementation**: Enabled `vector` extension and added an `embedding vector(384)` column to both `jobs` and `profiles` tables.
- **Custom Drizzle Type**: Implemented a custom Drizzle type in `schema/custom-types.ts` to cleanly handle parsing and serializing `[0.1, 0.2, ...]` vector arrays between TypeScript and the database.

### 2. Embedding Service
- **Model**: HuggingFace `sentence-transformers/all-MiniLM-L6-v2`. Chosen because it's fast, highly effective for sentence similarity, outputs small (384-dimensional) vectors, and runs for free on the HuggingFace Serverless Inference API.
- **Client (`lib/embeddings.ts`)**: Contains `generateEmbedding` and `generateBatchEmbeddings` functions. Includes built-in exponential backoff and retry logic to gracefully handle HuggingFace's "cold-start" delays when the model is first loaded into memory.

### 3. API Routes
- **`POST /api/embed/profile`**: Concatenates a user's summary, skills, experience, and projects into a rich text blob, sends it to HuggingFace, and saves the resulting vector to the user's profile.
- **`POST /api/embed/jobs`**: Finds up to 32 jobs without embeddings and batches them to HuggingFace for rapid processing.
- **`GET /api/jobs/ranked`**: The core semantic search query. Computes Cosine Similarity entirely within PostgreSQL using the `<=>` operator (`1 - (jobs.embedding <=> profile.embedding)`). Returns a `semanticScore` between 0.0 and 1.0.

### 4. Background Processing (Auto-embed)
- **Fire-and-Forget**: When a new job is fetched from Adzuna or imported via URL, the backend immediately kicks off an asynchronous background task to embed its description. This ensures the job is searchable semantically within seconds, without slowing down the initial user request.

### 5. Frontend UI
- **Dual Scoring System**: The `JobCard` component now dynamically displays two distinct scores:
  1. A gold **Keyword Match** percentage.
  2. A purple **Semantic Match** percentage (if the job has been embedded).
- **Manual Triggers**: Added "Embed Profile" and "Embed Jobs" buttons to the Job Discovery page header, allowing users to manually sync their vectors after updating their resumes.
- **Graceful Fallbacks**: The frontend attempts to load ranked jobs. If the user hasn't embedded their profile yet, it gracefully catches the 400 error and falls back to standard keyword-based sorting.
